# 低置信度的 none 也附带候选工具(软 need, T-020)

真实目录 2405 个工具,600 条 BFCL 请求。need 银标来自 `data/v3-primary/labeled_agree.jsonl`,工具银标是 Jev / Haiku 两路一致结果。

> 设置沿用 T-019:分类头和检索都用 `tfidf`,真实目录 + 双语索引 + 软过滤关 + top_k=5,请求头按 5 折折外训练(seed 不变);开发折 = 第 0-2 折,测试折 = 第 3-4 折,是否启用只看开发折,测试折只报一次。

> 主口径 = 走完整 `route`(need 误判计 0),但 `soft_candidates` 附带的那部分候选算数。阈值 `None` 是改前基线;`1.01` 相当于"判成 none 就一律附带候选"。


## 0. 结论(只看开发折)

开发折 360 条;1 条样本 = 1/360 = 0.28 个百分点。误挂率池 = 两路一致判成 none 的 alpaca_zh 480 条
基线(None)= 中文主口径严格 R@5 26.0%,误挂率 0.0%。

- 阈值 0.5: 中文严格 R@5 27.8%(+6.7 条);误挂率 0.0%(0/480);平均额外延迟 0.04 ms
- 阈值 0.6: 中文严格 R@5 31.8%(+21.0 条);误挂率 0.6%(3/480);平均额外延迟 0.24 ms
- 阈值 0.7: 中文严格 R@5 37.5%(+41.7 条);误挂率 2.5%(12/480);平均额外延迟 0.48 ms
- 阈值 0.8: 中文严格 R@5 43.6%(+63.5 条);误挂率 11.9%(57/480);平均额外延迟 0.68 ms
- 阈值 0.9: 中文严格 R@5 48.1%(+79.5 条);误挂率 56.9%(273/480);平均额外延迟 0.84 ms
- 阈值 1.01: 中文严格 R@5 51.0%(+90.0 条);误挂率 99.6%(478/480);平均额外延迟 0.94 ms

**结论**:误挂率 ≤ 10% 里开发折中文主口径严格 R@5 最高的是阈值 0.7(37.5%,+41.7 条;误挂率 2.5%)。建议启用该阈值;本卡不改默认值,是否改默认留待决策。
