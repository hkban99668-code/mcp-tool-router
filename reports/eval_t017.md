# T-017 第二路打标换成国产模型:小样本选型 + 全量对照

## 结论

- 选中的国产模型是 **deepseek/deepseek-v4.1-flash**(选型规则:与 Jev 的主指标最高,1 条样本以内并列时取平均 token 少的)。
- 它与 Jev 的 primary 双路一致率 82.4%(有效 210 条);Haiku 参考行 82.2%,差距 +0.4 条样本(无法区分)。据此:**可以替代 Haiku 做第二路(主指标与 Haiku 参考行无法区分)**。
- token 用量(每次调用平均):input 1829 / output 868 / reasoning 725。commandcode 不返回费用,Haiku 的 token 用量不在已有缓存里(按任务卡不重新问 Haiku),所以只能给国产模型自己的用量。
- 全量对照:见下面第 2 节,`data/v3-primary`(Jev + Haiku)与 `data/v3-primary-cn`(Jev + deepseek/deepseek-v4.1-flash)并排。
