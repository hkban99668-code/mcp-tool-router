# 当前默认配置的端到端快照(T-021)

真实目录 2405 个工具,600 条 BFCL 请求(600 条里能对上金标 tool_id 的部分)。need 银标来自 `data/v3-primary/labeled_agree.jsonl`,工具银标是 Jev / Haiku 两路一致结果。

> 请求头按 5 折折外训练(`assign_folds`,seed 不变):开发折 = 第 0-2 折(360 条),测试折 = 第 3-4 折(240 条),两套都报,本报告不做任何选择。

> 主口径 = 走完整 `route`(need 误判计 0);上限 = 假设 need 全对,纯检索天花板。软 need 开启时,附带 `soft_candidates` 的候选也算进主口径。

## 8. 从 T-012 到现在的总变化

开发折 360 条;对照 `reports/eval_e2e.md`(T-012)。1 条样本 = 1/360 = 0.28 个百分点。

- 主口径中文严格 R@5:26.0%(T-012) → 37.5%(现在),+41.7 条。
- 主口径中文同名 R@5:34.1%(T-012) → 49.0%(现在),+53.7 条。
- 主口径英文严格 R@5:58.3%(T-012) → 63.8%(现在),+20.0 条。
- 主口径英文同名 R@5:69.3%(T-012) → 75.6%(现在),+23.0 条。
- 软 need 触发:开发折 0 条 → 79 条。
- 从 T-012 到现在,线上默认只多了一个 `soft_need_threshold=0.7`;编码器(T-016/T-019)与去重(T-013)的结论都是维持 tfidf / 关,没有改默认。
